HTTP status codes

100–199 · Informational — Ενημέρωση για την πορεία του αιτήματος.

200–299 · Successful — Το αίτημα έγινε δεκτό ή ολοκληρώθηκε επιτυχώς.

300–399 · Redirection — Χρειάζεται ανακατεύθυνση ή χρήση αποθηκευμένης απάντησης.

400–499 · Client error — Υπάρχει πρόβλημα με το αίτημα ή την πρόσβαση.

500–599 · Server error — Υπάρχει πρόβλημα στην πλευρά του server.

Κατηγορία 100 Ενημερωτικές απαντήσεις

100 Continue

Ο server λέει στον client να συνεχίσει να στέλνει το αίτημα.

101 Switching Protocols

Ο server αλλάζει πρωτόκολλο, ύστερα από αίτημα του client. Παράδειγμα: σύνδεση WebSocket.

102 Processing

Το αίτημα έχει ληφθεί, αλλά η επεξεργασία δεν έχει τελειώσει. Παρωχημένος κωδικός WebDAV.

103 Early Hints

Ο browser παίρνει πρώιμες οδηγίες ώστε να αρχίσει να φορτώνει πόρους πριν έρθει η τελική απάντηση.

Κατηγορία 200 Επιτυχημένες απαντήσεις

200 OK

Το αίτημα πέτυχε. Παράδειγμα: ζητάμε τα στοιχεία ενός χρήστη με GET και τα λαμβάνουμε.

201 Created

Το αίτημα πέτυχε και δημιουργήθηκε νέος πόρος. Παράδειγμα: δημιουργία λογαριασμού με POST.

202 Accepted

Ο server δέχτηκε το αίτημα, αλλά δεν έχει ολοκληρώσει την εργασία. Παράδειγμα: δημιουργία report στο παρασκήνιο.

203 Non-Authoritative Information

Η απάντηση έχει τροποποιηθεί από ενδιάμεσο σύστημα και δεν είναι ακριβώς η αρχική απάντηση του server.

204 No Content

Η ενέργεια πέτυχε, αλλά δεν επιστρέφεται περιεχόμενο στο body. Παράδειγμα: επιτυχής διαγραφή.

205 Reset Content

Η ενέργεια πέτυχε και ο client πρέπει να επαναφέρει την προβολή εισαγωγής, π.χ. να καθαρίσει μια φόρμα.

206 Partial Content

Επιστρέφεται μόνο το τμήμα του πόρου που ζητήθηκε. Παράδειγμα: ένα κομμάτι αρχείου ή βίντεο.

207 Multi-Status

Η απάντηση περιλαμβάνει διαφορετικά αποτελέσματα για πολλούς πόρους ή ενέργειες. Χρησιμοποιείται στο WebDAV.

208 Already Reported

Οι σχετικές πληροφορίες έχουν ήδη εμφανιστεί αλλού στην ίδια απάντηση και δεν επαναλαμβάνονται. WebDAV.

226 IM Used

Ο server επιστρέφει αποτέλεσμα μετασχηματισμών ενός πόρου, π.χ. διαφορές από παλαιότερη έκδοση. Σπάνιος κωδικός.

Κατηγορία 300 Ανακατευθύνσεις

300 Multiple Choices

Υπάρχουν περισσότερες από μία διαθέσιμες επιλογές για τον πόρο. Ο client ή ο χρήστης πρέπει να επιλέξει.

301 Moved Permanently

Ο πόρος μεταφέρθηκε μόνιμα σε νέο URL. Παράδειγμα: μια παλιά σελίδα απέκτησε νέα διεύθυνση.

302 Found

Ο πόρος βρίσκεται προσωρινά σε άλλο URL. Η αρχική διεύθυνση παραμένει αυτή που χρησιμοποιούμε στο μέλλον.

303 See Other

Ο server μας στέλνει σε άλλο URL για να πάρουμε το αποτέλεσμα με GET. Συνηθισμένο μετά από υποβολή φόρμας.

304 Not Modified

Ο πόρος δεν έχει αλλάξει σε σχέση με την αποθηκευμένη έκδοση. Ο browser μπορεί να χρησιμοποιήσει την cache.

305 Use Proxy

Παλιός κωδικός που ζητούσε πρόσβαση μέσω proxy. Έχει καταργηθεί από τη συνιστώμενη χρήση.

306 unused

Δεν χρησιμοποιείται πλέον. Ο αριθμός παραμένει δεσμευμένος.

307 Temporary Redirect

Προσωρινή μεταφορά σε άλλο URL, με διατήρηση της μεθόδου και του body. Ένα POST παραμένει POST.

308 Permanent Redirect

Μόνιμη μεταφορά σε άλλο URL, με διατήρηση της μεθόδου και του body. Ένα POST παραμένει POST.

Να θυμόμαστε: 301 και 308 = μόνιμα. 302 και 307 = προσωρινά. Τα 307 και 308 απαιτούν να διατηρηθεί η μέθοδος· στα 301 και 302 ένα POST μπορεί να γίνει GET.

Κατηγορία 400 Σφάλματα client

400 Bad Request

Το αίτημα δεν είναι αποδεκτό. Παράδειγμα: στέλνουμε JSON με λάθος σύνταξη.

401 Unauthorized

Χρειάζεται έγκυρη ταυτοποίηση. Παράδειγμα: λείπει το token ή έχει λήξει.

402 Payment Required

Κωδικός σχετικός με πληρωμές, χωρίς ενιαίο καθιερωμένο τρόπο χρήσης. Η σημασία του εξαρτάται από το API.

403 Forbidden

Ο server αρνείται την πρόσβαση. Παράδειγμα: ένας απλός χρήστης προσπαθεί να κάνει ενέργεια διαχειριστή.

404 Not Found

Ο server δεν βρίσκει τον ζητούμενο πόρο. Παράδειγμα: χρήστης με ID που δεν υπάρχει.

405 Method Not Allowed

Η μέθοδος δεν επιτρέπεται σε αυτόν τον πόρο. Παράδειγμα: POST σε endpoint που δέχεται μόνο GET.

406 Not Acceptable

Ο server δεν μπορεί να δώσει απάντηση στη μορφή που δέχεται ο client, σύμφωνα με headers όπως το Accept.

407 Proxy Authentication Required

Χρειάζονται στοιχεία ταυτοποίησης για τον proxy, δηλαδή το ενδιάμεσο σύστημα.

408 Request Timeout

Ο server περίμενε υπερβολικά για να λάβει το αίτημα και τερματίζει την αναμονή.

409 Conflict

Το αίτημα συγκρούεται με την τρέχουσα κατάσταση. Παράδειγμα: δημιουργία εγγραφής με όνομα που ήδη χρησιμοποιείται.

410 Gone

Ο πόρος έχει αφαιρεθεί και η απουσία του θεωρείται μόνιμη.

411 Length Required

Ο server απαιτεί το header Content-Length, που δηλώνει το μέγεθος του body.

412 Precondition Failed

Δεν ισχύει μια προϋπόθεση που έστειλε ο client. Παράδειγμα: τα δεδομένα άλλαξαν από τότε που τα διάβασε.

413 Content Too Large

Το body είναι μεγαλύτερο από το όριο του server. Παράδειγμα: ανεβάζουμε υπερβολικά μεγάλο αρχείο.

Κατηγορία 400 Σφάλματα client

414 URI Too Long

Η διεύθυνση του αιτήματος είναι υπερβολικά μεγάλη. Παράδειγμα: πάρα πολλές παράμετροι στο URL.

415 Unsupported Media Type

Ο server δεν υποστηρίζει τη μορφή του body. Παράδειγμα: στέλνουμε XML ενώ το API περιμένει JSON.

416 Range Not Satisfiable

Το τμήμα αρχείου που ζητήθηκε δεν μπορεί να δοθεί. Παράδειγμα: ζητάμε bytes πέρα από το τέλος του.

417 Expectation Failed

Ο server δεν μπορεί να ικανοποιήσει την απαίτηση που δηλώνεται στο header Expect.

418 I'm a teapot

Χιουμοριστικός κωδικός: «είμαι τσαγιέρα, δεν φτιάχνω καφέ». Δεν είναι συνηθισμένο λειτουργικό σφάλμα API.

421 Misdirected Request

Το αίτημα έφτασε σε server που δεν μπορεί να απαντήσει για τον συγκεκριμένο προορισμό.

422 Unprocessable Content

Η σύνταξη είναι σωστή, αλλά τα δεδομένα δεν μπορούν να γίνουν αποδεκτά. Παράδειγμα: μη επιτρεπτή τιμή πεδίου.

423 Locked

Ο πόρος είναι κλειδωμένος και η ενέργεια δεν μπορεί να εκτελεστεί. Χρησιμοποιείται στο WebDAV.

424 Failed Dependency

Η ενέργεια απέτυχε επειδή απέτυχε κάποια άλλη από την οποία εξαρτάται. Χρησιμοποιείται στο WebDAV.

425 Too Early

Ο server αποφεύγει την επεξεργασία αιτήματος που στάλθηκε νωρίς, λόγω κινδύνου επανάληψής του.

426 Upgrade Required

Ο client πρέπει να χρησιμοποιήσει άλλο πρωτόκολλο. Ο server το δηλώνει στο header Upgrade.

428 Precondition Required

Ο server απαιτεί προϋπόθεση στο αίτημα, ώστε π.χ. να μη χαθούν αλλαγές άλλου χρήστη.

429 Too Many Requests

Έχουν σταλεί υπερβολικά πολλά αιτήματα σε λίγο χρόνο. Έχει ενεργοποιηθεί το όριο αιτημάτων.

431 Request Header Fields Too Large

Ένα ή περισσότερα headers είναι υπερβολικά μεγάλα. Παράδειγμα: πολύ μεγάλο header Cookie.

451 Unavailable For Legal Reasons

Ο πόρος δεν μπορεί να δοθεί για νομικούς λόγους.

Κατηγορία 500 Σφάλματα server

500 Internal Server Error

Κάτι απρόβλεπτο απέτυχε στον server. Είναι γενικό σφάλμα, χωρίς πιο συγκεκριμένη ένδειξη.

501 Not Implemented

Ο server δεν υποστηρίζει τη λειτουργία που απαιτείται, π.χ. μια μέθοδο που δεν έχει υλοποιήσει.

502 Bad Gateway

Ένας ενδιάμεσος server πήρε μη έγκυρη απάντηση από τον επόμενο server.

503 Service Unavailable

Η υπηρεσία δεν μπορεί προσωρινά να εξυπηρετήσει. Παράδειγμα: συντήρηση ή υπερφόρτωση.

504 Gateway Timeout

Ένας ενδιάμεσος server περίμενε απάντηση από τον επόμενο server, αλλά αυτή άργησε υπερβολικά.

505 HTTP Version Not Supported

Ο server δεν υποστηρίζει την έκδοση HTTP του αιτήματος.

506 Variant Also Negotiates

Λάθος ρύθμιση δημιουργεί κύκλο κατά την επιλογή της κατάλληλης μορφής περιεχομένου.

507 Insufficient Storage

Ο server δεν έχει αρκετό διαθέσιμο χώρο για να ολοκληρώσει την ενέργεια. Χρησιμοποιείται στο WebDAV.

508 Loop Detected

Ο server εντόπισε ατέρμονο βρόχο κατά την επεξεργασία. Χρησιμοποιείται στο WebDAV.

510 Not Extended

Το αίτημα απαιτεί επέκταση HTTP που δεν υποστηρίζεται. Παρωχημένος κωδικός.

511 Network Authentication Required

Απαιτείται σύνδεση για πρόσβαση στο δίκτυο. Παράδειγμα: σελίδα εισόδου δημόσιου Wi-Fi.

Οι σημαντικότεροι που συναντάμε

Για να ξεκινήσουμε με web και API testing, μαθαίνουμε πρώτα τους παρακάτω. Η συχνότητά τους διαφέρει ανά εφαρμογή.

200 OK — Το αίτημα πέτυχε.

201 Created — Δημιουργήθηκε νέος πόρος.

204 No Content — Επιτυχία χωρίς περιεχόμενο στο body.

301 Moved Permanently και 302 Found — Μόνιμη και προσωρινή ανακατεύθυνση αντίστοιχα.

304 Not Modified — Χρήση της αποθηκευμένης έκδοσης από την cache.

400 Bad Request — Μη αποδεκτό αίτημα.

401 Unauthorized — Λείπει έγκυρη ταυτοποίηση.

403 Forbidden — Δεν επιτρέπεται η πρόσβαση.

404 Not Found — Δεν βρέθηκε ο πόρος.

405 Method Not Allowed — Δεν επιτρέπεται η μέθοδος.

409 Conflict — Σύγκρουση με υπάρχοντα δεδομένα ή κατάσταση.

415 Unsupported Media Type — Λάθος ή μη υποστηριζόμενη μορφή body.

422 Unprocessable Content — Σωστή σύνταξη, αλλά μη αποδεκτά δεδομένα.

429 Too Many Requests — Υπέρβαση ορίου αιτημάτων.

500 Internal Server Error — Γενικό σφάλμα server.

502 Bad Gateway — Μη έγκυρη απάντηση από άλλον server.

503 Service Unavailable — Προσωρινά μη διαθέσιμη υπηρεσία.

504 Gateway Timeout — Καθυστέρηση απάντησης από άλλον server.
