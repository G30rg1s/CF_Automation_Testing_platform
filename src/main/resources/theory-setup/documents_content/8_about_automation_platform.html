1. Περιγραφή εφαρμογής

Το Automation Platform είναι μια εφαρμογή που εκτελείται τοπικά στον υπολογιστή του χρήστη μέσω Docker.

Η εφαρμογή έχει δύο βασικούς σκοπούς:

Εκπαίδευση και εξάσκηση: Αποτελεί βάση οργάνωσης και μελέτης θεωρίας, εκπαιδευτικών εγγράφων και quizzes. Ο χρήστης μπορεί να αποθηκεύει εκπαιδευτικό υλικό, να το οργανώνει σε κατηγορίες, να μελετά το περιεχόμενό του και να ελέγχει τις γνώσεις του μέσα από διαδραστικά quizzes.

Automation Testing: Η ίδια η εφαρμογή αποτελεί το σύστημα στο οποίο πραγματοποιούνται αυτοματοποιημένες δοκιμές. Οι σελίδες, οι φόρμες και οι λειτουργίες της χρησιμοποιούνται ως βάση για τη δημιουργία και εκτέλεση διαφορετικών σεναρίων ελέγχου.

2. Βασικές δυνατότητες και Use Cases

Σελίδα / ΛειτουργίαΒασικές δυνατότητεςUse Cases
DashboardΚεντρική σελίδα της εφαρμογής και πρόσβαση στις διαθέσιμες λειτουργίες.Ο χρήστης περιηγείται στις ενότητες της εφαρμογής και επιλέγει τη λειτουργία που επιθυμεί.
My ProfileΠροβολή και διαχείριση προσωπικών στοιχείων.Ο χρήστης προβάλλει και ενημερώνει τα στοιχεία του λογαριασμού του.
Upload DocumentΑνέβασμα εγγράφων και ασύγχρονη επεξεργασία του περιεχομένου τους από parser.Ο χρήστης ανεβάζει ένα έγγραφο, επιλέγει τον τύπο του και το ανοίγει μετά την επεξεργασία για μελέτη ή quiz.
CategoriesΔημιουργία, προβολή και διαγραφή κατηγοριών.Ο χρήστης οργανώνει το εκπαιδευτικό υλικό του ανά θεματική ενότητα.
Document ManagementΠροβολή, μετονομασία, αντικατάσταση και διαγραφή εγγράφων.Ο χρήστης διαχειρίζεται τα αποθηκευμένα έγγραφα και ενημερώνει το εκπαιδευτικό υλικό του.
Document Details Προβολή και ανάγνωση του περιεχομένου των εγγράφων.Ο χρήστης ανοίγει ένα έγγραφο και μελετά τη θεωρία που περιέχει.

QuizzesΣυμπλήρωση ερωτήσεων, υποβολή απαντήσεων και προβολή αποτελεσμάτων.Ο χρήστης εξασκείται πάνω στην εκπαιδευτική ύλη και αξιολογεί τις γνώσεις του.
Manage DatabaseΕπιλογή βάσης δεδομένων και πρόσβαση στις διαθέσιμες λειτουργίες διαχείρισης.Ο χρήστης επιλέγει τη βάση δεδομένων στην οποία επιθυμεί να εργαστεί.
SQL Query ConsoleΔημιουργία, αποθήκευση, αναζήτηση, επεξεργασία, εκτέλεση, αντιγραφή και διαγραφή SQL queries.Ο χρήστης αποθηκεύει SQL queries, τα επαναχρησιμοποιεί και προβάλλει τα αποτελέσματα της εκτέλεσής τους.
Application LogsΠροβολή καταγραφών λειτουργίας της εφαρμογής.Ο χρήστης εξετάζει τις καταγραφές για να ενημερωθεί σχετικά με τη λειτουργία της εφαρμογής.
Automation TestingΧρήση των λειτουργιών της εφαρμογής ως σενάρια αυτοματοποιημένου ελέγχου.Οι ενέργειες των χρηστών, όπως η διαχείριση εγγράφων, η συμπλήρωση φορμών και η εκτέλεση quizzes, αποτελούν σενάρια για αυτοματοποιημένες δοκιμές.

3. Ανέβασμα και επεξεργασία εγγράφων

Κατά το Upload Document, το αρχείο αποθηκεύεται και ο parser επεξεργάζεται το περιεχόμενό του ασύγχρονα, χωρίς ο χρήστης να χρειάζεται να παραμείνει στη σελίδα μέχρι να ολοκληρωθεί η επεξεργασία. Στη συνέχεια, το περιεχόμενο μορφοποιείται και παρουσιάζεται σύμφωνα με τον τύπο εγγράφου: για παράδειγμα, ένα έγγραφο TYPE = Document εμφανίζεται για ανάγνωση και μελέτη, ενώ ένα έγγραφο TYPE = Quiz διαβάζεται και εμφανίζεται ως ερωτήσεις για εξάσκηση.

4. Τρόπος χρήσης

Ο χρήστης εκκινεί το Automation Platform μέσω Docker στον υπολογιστή του και αποκτά πρόσβαση στις λειτουργίες της εφαρμογής.

Μπορεί να ανεβάζει εκπαιδευτικά έγγραφα, να τα οργανώνει ανά κατηγορία, να ανοίγει το περιεχόμενό τους για μελέτη και να πραγματοποιεί quizzes.

Παράλληλα, έχει τη δυνατότητα να διαχειρίζεται τα στοιχεία του λογαριασμού του, να επιλέγει τη διαθέσιμη βάση δεδομένων, να χρησιμοποιεί το SQL Query Console και να προβάλλει τις καταγραφές της εφαρμογής.

Οι ίδιες λειτουργίες αποτελούν επίσης τη βάση για τη δημιουργία και εκτέλεση σεναρίων αυτοματοποιημένου ελέγχου.
